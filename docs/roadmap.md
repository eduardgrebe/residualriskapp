# Development roadmap

## Current status

This software is currently in beta. The current version of the deployed webapp and the Python library can be seen in the sidebar on the left.

## Release roadmap

* **Promotion from beta to stable release:** The first stable release will be v1.1.0 (v1.0.0 is an abandoned line that excluded the PrEP risk model). *Timeframe:*: August 2026.
* **Version 1.2:** Version 1.2.0 will include several new features:
  * Tools to estimate PrEP breakthrough HIV infection incidence in blood donors using population-level PrEP uptake, donor disclosure and PrEP target population donation rates.
  * Additional options for specifying HIV transmissibility parameters.
  * Improved documentation and guidance for use in various scenarios.
  * Integration of any newly-published data on PrEP breakthrough infection detectabilit and infectiousness.
  * *Timeframe:* ~December 2026.
* **Version 2.0:** This will be a major version uograde. Targeted features are not fully settled, but may include:
  * Explicitly modelling drug concentration dynamics.
  * Drug-specific potency/effect on transmissibility.
  * Modelling HBV and HCV transfusion-transmission risk.
  * Addition of sophisticated scenario modelling and sensitivity analysis tools.
  * *Timeframe:* TBD.
